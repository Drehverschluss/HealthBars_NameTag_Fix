
# HealthBars NameTag Fix

Small client-side fix mod for HealthBars on Minecraft 1.21.1 / NeoForge 21.1.248.

The mod restores name tag visibility for entities that always have a permanent
name tag flag (for example MineColonies citizens), even when HealthBars would
otherwise hide the name via `no_health_bar_mobs` or `hide_at_full_health`.
